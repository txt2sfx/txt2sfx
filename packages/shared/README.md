# @txt2sfx/shared

Shared types and physical constants for [txt2sfx](https://github.com/txt2sfx/txt2sfx) — the vocabulary every other `@txt2sfx/*` package speaks. Types plus a table of constants, zero runtime dependencies and zero behaviour, so it imports the same from a browser, from Node and from a worker.

You rarely install this directly; it arrives as a dependency of `@txt2sfx/core` and the packages above it. The interesting entry points are there.

All `@txt2sfx/*` packages are published in lockstep from one commit — install them at one version.

Apache-2.0.
